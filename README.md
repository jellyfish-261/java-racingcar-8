# java-racingcar-precourse

### 기능 목록

- 자동차 이름 입력받기 (쉼표(,) 분리, 5자 이하 및 공백 검증)
- 시도 횟수 입력받기 (숫자 여부 및 1 이상 검증)
- Car 객체 생성 (이름과 위치 상태를 관리하며, 랜덤값이 4 이상일 때 전진하는 로직 구현)
- 1회 레이스 실행 (각 Car별 랜덤값(0-9) 생성 및 4 이상일 때 전진)
- 1회 실행 결과 출력 (이름 : --- 형식으로 현재 위치 표시)
- 최종 우승자 판별 (최대 위치값 탐색, 공동 우승자 처리)
- 최종 우승자 출력 (최종 우승자 : 이름1, 이름2 형식)
- 전체 게임 흐름 제어 (사용자 입력부터 결과 출력까지 전체 실행 흐름을 연결)
